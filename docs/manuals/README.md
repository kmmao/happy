# Happy Manuals

这个目录用于集中放 Happy 自主 loop / 自动化系统的操作文档。

## 目录

### Getting Started

- 快速上手操作手册：`docs/manuals/getting-started/happy-loop-operator-manual.md`

适合：

- 第一次启用 Happy 自主 loop
- 想快速知道 CLI / UI 应该怎么用
- 想按顺序完成从创建 loop 到查看 brief / memory / Auto-Dream 的闭环

### Best Practices

- 最佳实践：`docs/manuals/best-practices/happy-loop-best-practices.md`

适合：

- 想知道什么场景适合建 loop
- 想知道默认推荐参数怎么配
- 想避免 loop 失控、过频、无边界运行

### Troubleshooting

- 故障排查：`docs/manuals/troubleshooting/happy-loop-troubleshooting.md`

适合：

- loop 不跑
- brief / memory / context 不更新
- Auto-Dream 不出 report
- automation 页面出现异常

### Operations

- 日常运营手册：`docs/manuals/operations/happy-loop-operations-playbook.md`
- 巡检与复盘清单：`docs/manuals/operations/happy-loop-review-checklists.md`

适合：

- 想建立每日 / 每周 / 每月运营节奏
- 想知道哪些 loop 应该保留、暂停、收紧或下线

### FAQ

- 常见问题：`docs/manuals/faq/happy-loop-faq.md`

适合：

- 快速理解概念区别
- 快速判断某个现象是不是预期

### Templates

- 模板库：`docs/manuals/templates/happy-loop-templates.md`

适合：

- 直接复制可用的 loop 配置
- 想快速从“会用”进入“配得合理”

### Reference

- 命令参考：`docs/manuals/reference/happy-loop-command-reference.md`
- 状态字段参考：`docs/manuals/reference/happy-loop-state-reference.md`

适合：

- 忘记某个参数怎么写
- 想查某个状态字段到底是什么意思
- 想快速查 UI 指标与 CLI 字段

### Roadmap

- 路线图与交接说明：`docs/manuals/roadmap/happy-loop-roadmap-and-handoff.md`

适合：

- 想知道当前已实现边界
- 想知道明确未实现项
- 想给后续开发者做接力交接
