## 3. 状态机事件流

```mermaid
stateDiagram-v2
    [*] --> off

    off --> idle : toggle(enabled=true)\n+ contextReady=false
    off --> armed : toggle(enabled=true)\n+ contextReady=true\n+ candidate≠null

    idle --> armed : options-updated\n+ isContextReady\n+ candidate≠null\n+ lastSentKey≠candidateKey

    armed --> idle : context-invalidated\n(输入框/切会话/stale/AskUserQuestion)
    armed --> ready : timer-finished (15s)

    ready --> idle : attempt-fire\ncanFire=false

    ready --> idle : attempt-fire\ncanFire=true\n[sendMessage() 执行]

    note right of armed
        副作用：
        startTimer(15s)
        triggerSemanticScoring
    end note

    note right of ready
        canFire 检查：
        - optionsHash 一致
        - sourceMessageId 一致
        - lastAutoSentKey ≠ candidateKey
    end note
```

## 4. 数据流：Claude 回复 → 自动发送

```mermaid
sequenceDiagram
    participant Claude
    participant SV as SessionView
    participant SVC as autoOptionSendService
    participant SM as autoOptionSend(SM)
    participant Server

    Claude->>SV: 回复消息（含/不含 options）

    alt 含 <options> blocks
        SV->>SVC: triggerScoringIfNeeded(items, hash)
        SVC->>Server: POST /v1/options/score
        Server-->>SVC: { scores[], modelUsed }
        SVC->>SVC: semanticScores.set(hash, scores)
        SVC->>SV: setState({...}) → re-render
        Note over SV: llmScoredIndices 更新\n✨ badge 显示
    end

    SVC->>SV: onReady(sessionId)
    SVC->>SM: checkAndDispatch → options-updated

    alt 无 <options>，auto-send 开启
        SVC->>Server: POST /v1/options/generate
        Server-->>SVC: { options[] }
        SVC->>SVC: generatedOptions.set(sessionId, options)
        SVC->>SM: checkAndDispatch → options-updated
    end

    SM-->>SVC: state = armed
    SVC->>SVC: startTimer(15s)
    SVC->>Server: POST /v1/options/score (semantic scoring)
    Server-->>SVC: { scores[], modelUsed }
    SVC->>SM: update candidate.recommendedText

    Note over SVC: 15s 倒计时...

    SVC->>SM: timer-finished → state = ready
    SVC->>SM: attempt-fire → canFire?

    alt canFire = true
        SVC->>Claude: sendMessage(recommendedText)
        SVC->>SVC: lastAutoSentKey = hash:sourceId
        SVC->>SVC: recordFeedback(send)
    else canFire = false
        SVC->>SM: state = idle (fire-check-failed)
    end
```
