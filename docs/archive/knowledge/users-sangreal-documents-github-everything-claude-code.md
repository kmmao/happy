## Inbox notifications now include referenceUrl for correct navigation

*fix · high · 2026-04-06*

Inbox notifications were missing the referenceUrl field, which prevented correct navigation when users tapped on notifications. The fix adds referenceUrl to the notification payload, enabling proper routing to the intended destination when a user interacts with an inbox notification.
